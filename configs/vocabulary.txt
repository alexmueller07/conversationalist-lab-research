# Names the recognizer would otherwise get wrong.

# One entry per line. Blank lines and lines starting with '#' are ignored.
# Entries are used twice: to bias the recognizer while it is decoding, and
# to repair close phonetic misses afterwards. Every repair is listed in the
# session report, so nothing is changed silently.
#
# ADD TO THIS FILE when you notice a name coming out wrong. That is the fix
# -- it needs no code change and no new model, only a re-run of the affected
# sessions. Write the entry the way it should appear in the transcript,
# including capitalisation.
#
# Do NOT add ordinary words. The repair pass will not rewrite a common word
# on its own, but a vocabulary full of everyday vocabulary makes the
# decoder's bias useless by diluting it.
#
# NEVER add participant names or anything else identifying. This file is
# committed to the repository; IRB protocol 2020-1657 keeps identifiers out
# of source control.
